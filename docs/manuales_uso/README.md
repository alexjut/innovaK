# Manuales de uso — innovaK / KennedyConecta

Manuales de uso de la plataforma, **uno por área/rol**, que se entregan a las
personas a medida que se les crea el usuario. Cada manual está escrito para el
usuario final (paso a paso, sin tecnicismos) y sirve de base para la
capacitación.

> El registro de **quién** recibió acceso (datos, rol, estado) está en
> [`../usuarios_solicitados.md`](../usuarios_solicitados.md).

## Cómo se agrega un manual nuevo

Cuando se entregue acceso a un área nueva:
1. Crear `docs/manuales_uso/<area>.md` (copiar la estructura de `cultura.md`).
2. Ajustar las secciones a los módulos de su rol.
3. Agregar la fila en este índice y marcar el estado en
   `../usuarios_solicitados.md`.
